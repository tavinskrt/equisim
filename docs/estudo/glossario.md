# Glossário

Termos que aparecem no aplicativo, no painel de logs e nesta documentação, em
ordem alfabética. Entre parênteses, o capítulo onde o termo é explicado com
calma.

| Termo | O que é |
|---|---|
| **Ação ordinária (ON) / preferencial (PN)** | Classes de ação. A ON vota; a PN tem preferência em dividendos. Uma empresa pode ter as duas na bolsa (cap. 2). |
| **Alavancagem** | Quanto a empresa usa de dívida. No motor: dívida líquida ÷ EBITDA (para o prêmio de crédito) e dívida ÷ patrimônio (para o beta) (cap. 3). |
| **Alíquota efetiva / estrutural / estatutária** | Efetiva: imposto pago ÷ lucro antes do imposto num ano. Estrutural: a mediana das efetivas, que o motor usa no NOPAT. Estatutária: 34% (IRPJ 25% + CSLL 9%), usada no escudo fiscal (cap. 2). |
| **AR(1)** | Modelo em que o valor de um ano depende do anterior multiplicado por φ. Mede persistência (cap. 6). |
| **Backtest** | Rodar o motor em datas passadas, só com o que se sabia então, e comparar com o que aconteceu (cap. 6 e 7). |
| **Base (lucro-base)** | O lucro de partida da projeção, depois da normalização (cap. 4). |
| **Beta (β)** | Quanto a ação se move quando o Ibovespa se move 1% (cap. 3). |
| **Beta desalavancado (β_U)** | O beta sem o efeito da dívida: o risco do negócio (cap. 3). |
| **Book-to-market (B/M)** | Patrimônio ÷ valor de mercado. Fator de "valor" da literatura (cap. 7). |
| **Capital investido** | Patrimônio líquido + dívida líquida: o dinheiro posto na operação (cap. 2). |
| **Capital posterior** | Ações emitidas depois do último balanço; entram na contagem e são somadas ao capital próprio (cap. 4). |
| **CAPM** | Ke = taxa livre de risco + β × prêmio de mercado (cap. 3). |
| **Cascata** | A sequência de portas que decide se e como a empresa é avaliada (cap. 4). |
| **CDI** | Taxa dos empréstimos de um dia entre bancos, colada à Selic (cap. 3). |
| **Cenários** | Três conjuntos fixos de premissas (pessimista, base, otimista): sensibilidade, não probabilidade (cap. 4). |
| **Ciclo (retorno do ciclo)** | A mediana do retorno sobre o capital nos oito exercícios anteriores (cap. 4). |
| **Cobertura (de juros)** | EBIT ÷ despesa financeira. Quantas vezes o lucro operacional paga os juros (cap. 3). |
| **Coorte** | Uma data de avaliação no backtest (cap. 6). |
| **Concessão** | Negócio operado sob contrato com prazo (saneamento, energia, rodovias) (cap. 4). |
| **Convenção de meio de ano** | Multiplicar cada valor presente por √(1 + taxa), porque o caixa chega ao longo do ano (cap. 1). |
| **Curva de juros** | As taxas dos títulos prefixados para cada prazo (cap. 3). |
| **CVM** | Comissão de Valores Mobiliários, que recebe os balanços oficiais (cap. 2). |
| **DCF** | Fluxo de caixa descontado: somar os fluxos futuros trazidos a valor de hoje (cap. 1 e 4). |
| **Desconto (taxa de)** | A taxa usada para trazer o futuro para hoje (cap. 1). |
| **Determinístico** | A mesma entrada dá sempre a mesma saída. Exigência do projeto (cap. 6). |
| **Dívida bruta / líquida** | Bruta: todos os empréstimos. Líquida: bruta menos o caixa (cap. 2). |
| **DRE** | Demonstração do resultado do exercício (cap. 2). |
| **EBIT / EBITDA** | Resultado operacional, antes de juros e imposto; o EBITDA também antes da depreciação (cap. 2). |
| **Encolhimento (*shrinkage*)** | Puxar uma estimativa imprecisa na direção de uma referência, ponderando pela precisão (cap. 3 e 6). |
| **Erro-padrão** | Quanto uma estimativa varia de amostra para amostra (cap. 6). |
| **Escudo fiscal** | A economia de imposto que a dedução dos juros gera: juro × 34% (cap. 3). |
| **EVA / excedente** | Lucro acima do custo do capital: NOPAT − custo × capital (cap. 4). |
| **Faixa calibrada** | Faixa de preço que conteve 80% dos casos passados, medida fora da amostra (cap. 4 e 7). |
| **Fama-MacBeth** | Regressão em cada coorte e média das inclinações; teste de habilidade (cap. 6). |
| **FCFF / FCFE** | Fluxo de caixa livre da firma (para todos os financiadores) / do acionista (cap. 4). |
| **Fisher (equação de)** | Taxa real = (1 + nominal) ÷ (1 + inflação) − 1 (cap. 1). |
| **Forward (taxa a termo)** | A taxa que a curva embute para um ano futuro específico (cap. 3). |
| **g / g∞** | Crescimento anual / crescimento perpétuo (cap. 4). |
| **Gabarito** | A saída completa do motor para 376 ativos, congelada e conferida a cada mudança (cap. 7). |
| **Gordon (fórmula de)** | Valor de um fluxo que cresce para sempre: F ÷ (r − g) (cap. 1). |
| **Hamada** | Fórmula que liga beta, dívida e imposto (cap. 3). |
| **IC (*information coefficient*)** | Correlação entre as posições do upside e as do retorno realizado (cap. 6). |
| **Ke** | Custo do capital próprio: o retorno que o sócio exige (cap. 3). |
| **Kd** | Custo da dívida: taxa livre de risco + prêmio de crédito (cap. 3). |
| **LPA** | Lucro por ação (cap. 5). |
| **Mediana** | O valor do meio de uma lista ordenada; resiste a extremos (cap. 6). |
| **Minoritários** | A parte das controladas que não pertence ao acionista da controladora (cap. 4). |
| **Monte Carlo** | Recalcular o preço justo com milhares de premissas sorteadas (cap. 4 e 6). |
| **Moat (vantagem competitiva residual)** | Retorno acima do custo que sobrevive depois de dez anos, medido por φ¹⁰ (cap. 4). |
| **Múltiplos de pares** | P/L, P/VP e EV/EBITDA medianos de empresas parecidas, usados como segunda leitura (cap. 4). |
| **Newey-West** | Erro-padrão que considera que os erros de uma série no tempo se parecem entre si (cap. 6). |
| **NOPAT** | Lucro operacional depois do imposto, como se não houvesse dívida (cap. 2). |
| **Normalização** | Ajustar o lucro de partida pelo retorno típico do ciclo (cap. 4). |
| **Painel de logs** | A tela que mostra cada passo de cada avaliação ([AUDITORIA_DE_CALCULOS.md](../AUDITORIA_DE_CALCULOS.md)). |
| **Patrimônio líquido (PL)** | O que sobra para os sócios: ativos menos passivos (cap. 2). |
| **Percentil** | O valor abaixo do qual está uma fração dos dados (P5 = 5%) (cap. 6). |
| **Perpetuidade** | Fluxo que continua para sempre (cap. 1). |
| ***Point-in-time*** | Usar só o dado já publicado na data da avaliação (cap. 2). |
| **Poder (de um teste)** | A chance de um teste detectar um efeito que existe (cap. 6 e 7). |
| **Ponto fixo** | Repetir uma conta até que o resultado pare de mudar; usado no custo de capital (cap. 3). |
| **Porta** | Cada decisão da cascata: elegibilidade, setor, fluxo operacional, premissas (cap. 4). |
| **Prêmio de crédito (*spread*)** | O quanto a empresa paga acima da taxa livre de risco para se endividar (cap. 3). |
| **Prêmio de risco de mercado** | Quanto o investidor exige acima da renda fixa para ficar em ações. No motor, a média de dez anos do prêmio implícito: 1,21% em 14/09/2026 (cap. 3). |
| **Prêmio implícito** | O prêmio que o preço da bolsa embute: o retorno que iguala o valor de mercado das companhias aos dividendos que elas pagam, menos a taxa do Tesouro (cap. 3). |
| **Preço justo** | O valor por ação que as premissas do motor implicam (cap. 4). |
| **Regressão linear** | A reta que melhor passa por pontos (cap. 6). |
| **Ressalva** | Aviso estruturado de que o número é frágil num ponto específico (cap. 4). |
| **Retenção (b)** | Fração do lucro reinvestida para crescer: b = g ÷ ROIC (cap. 2). |
| **ROE / ROIC** | Retorno sobre o patrimônio / sobre o capital investido (cap. 2). |
| **RONIC** | Retorno sobre o capital **novo**, depois do ano 10 (cap. 4). |
| **Rastro (de auditoria)** | O registro de cada passo de uma avaliação, que o painel de logs mostra. |
| **Selic** | A taxa básica de juros definida pelo Banco Central (cap. 3). |
| **Significância (α)** | A chance aceita de chamar de real algo que é ruído; o motor usa 10% (cap. 6). |
| **Taxa livre de risco (Rf)** | O que rende um investimento que quase certamente paga (cap. 1 e 3). |
| **Terminal (valor terminal)** | O valor de tudo depois do ano 10, resumido numa perpetuidade (cap. 4). |
| **Unit** | Pacote de ações negociado como um papel; a SAPR11 é 1 ON + 4 PN (cap. 2). |
| **Upside (potencial)** | (Preço justo − preço) ÷ preço, total, sem prazo (cap. 4). |
| **Via da firma / do acionista** | Os dois caminhos de avaliação do motor (cap. 4 e 5). |
| **Volatilidade** | Desvio-padrão dos retornos diários × √252 (cap. 3). |
| **WACC** | Custo médio ponderado de capital: a média de Ke e Kd pelos pesos de ações e dívida (cap. 3). |
| **z robusto** | Distância até a mediana medida em MADs (cap. 6). |
